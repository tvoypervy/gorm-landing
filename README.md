# GORM - Branding & Digital Design Studio

An elegant and modern landing page for a creative digital studio, built from a Figma mockup. This project demonstrates advanced typography, complex CSS grids, and seamless micro-animations.

## 🚀 Tech Stack

- **HTML5** (Semantic markup)
- **SCSS** (Styled using the BEM methodology)
- **CSS Flexbox & Grid** (Responsive and rigid layouts for galleries and partner logos)
- **CSS Animations** (Infinite marquee scrolling effect)

## 🌟 Project Features

- **Modular Style Architecture:** Each logical block (header, greeting, work, experiences, footer) is separated into its own `.scss` file for better scalability and maintenance.
- **Pixel-Perfect Approach:** Precise implementation of paddings, font sizes (using `clamp` for responsiveness), and color palettes based on the original design.
- **Interactivity:** Smooth hover effects applied to cards, buttons, and navigation links.
